# 文字层级：一屏只允许三层

问题不是「文案写得不好」，是**说明没有按需出现的位置**，于是只能常驻。
每张卡都带一段解释，用户每次扫设置都要把已经知道的事再读一遍——这就是拥挤感的来源。

## 规则

1. **L1 标题**：是什么。≤ 8 字。
2. **L2 状态 / 值**：现在是怎样。一行，≤ 18 字。**只有会改变下一步动作的状态才配这一行**
   （「需重新登录」「1 件临期」「正在同步」）；解释性的句子不配。
3. **L3 说明**：怎么运作、为什么这样设计。**不许常驻在总览页**。只允许出现在三个地方：
   - **空态**：这一屏没东西可看时，教一次；
   - **首次使用 / 引导**；
   - **动作发生的那一刻**：确认、失败、权限缺失。
4. **一次承诺只说一遍**：「不联网 / 不上传 / 加密存本机」在设置页末尾出现一次，
   不再复制到每张卡。
5. **警告只在可行动时出现**：一句状态 + 一个动作能解决；解决不了的写进空态，不写进红条。
6. **不解释标签已经说清的事**：标签是「解析规则」，就不必再说「哪些短信认不出来，你自己定一条」。

## 判断方法

删之前问三句：

- 用户在这一屏**必须**知道它才能做对下一步吗？→ 是：留成 L2，一行。
- 不知道它会不会做错？→ 是：挪到动作发生时（确认 / 失败 / 空态）。
- 只是「我们想让他知道」？→ 删，或者放进空态 / 关于。

## 落地位置

- **设置**：每张卡只剩标题 + 状态；末尾一行收拢隐私承诺。
- **通知来源**：不可逆后果只在关掉那一刻说；代理转发的警告在第一次点击时才展开。
- **账号 / 规则 / 收容**：总览一句话；长解释留给空态和编辑屏。
- **首页**：只保留「这次真的需要你看一眼」的状态条，不常驻教程。

## 反例（这次删掉的）

| 位置 | 原文 | 问题 |
|---|---|---|
| 设置 · 平台账号 | 「绑定后从京东 / 淘宝 / 拼多多的订单里收录件；凭据加密存本机。」 | 标题已说明；信任承诺被复制了 4 次 |
| 设置 · 分组名 | 「现场模式里那个分组现在叫「帮妈妈取」。改成你家里实际的说法。」 | 把输入框里的值又念了一遍 |
| 设置 · 每天提醒 | 两行解释 + 权限警告 | 三层文字压一个开关，且解释只在开关打开时才相关 |
| 通知来源 · 顶部 | 99 字的三段式说明 | 常驻的教学；应留到空态与确认时 |
