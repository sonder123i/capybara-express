抓取失败被当成「同步成功」

高
app/src/main/java/dev/showcode/data/AccountSyncEngine.kt · 41–48 · 置信度 2/2
触发条件
Cookie 过期、平台风控、页面改版，或系统 WebView 不支持 document-start 注入导致提前返回空列表。
影响
账号状态与实际登录状态不一致；用户以为在正常同步，实际长期拿不到新件，排查时容易先怀疑 App 卡顿。
机制

修复方向
让抓取结果区分「成功但 0 件」与「失败」；失败时置 EXPIRED（或新增错误态）并给出「需要重新登录」的文案；仅在实际拿到响应时写入 last_sync_at。

中
app/src/main/java/dev/showcode/data/fetch/PddFetcher.kt · 315–320 · 置信度 2/2
触发条件
WebView 渲染进程崩溃、页面被销毁，或 evaluateJavascript 的回调未送达。
影响
accountSyncing 永不回到 null：该平台同步按钮消失，所有平台的同步也会被并发门拦住，只能重启 App 恢复。

    }   // 回调不来就永远挂起

- CREATE UNIQUE INDEX parcel_dedupe ON parcel(code, point_key) WHERE picked = 0
+ CREATE UNIQUE INDEX parcel_dedupe ON parcel(code, point_key)
