# 演示模式录制脚本（宣传片素材）

> 目标：一条约 80 秒、可截帧、可重复的演示片。
> 数据全部来自内存演示集，商品图全部来自 APK 内置素材；录制过程不出现任何系统框。

## 一、录制前

1. 安装 debug APK，清空应用数据（`adb shell pm clear dev.showcode`），保证从引导页开始。
2. 首次进入：在欢迎页点**「先看完整演示」**（次级按钮），直接落到演示首页。
3. 已有数据时：设置页拉到底 → **「演示模式（宣传片录制）」**，同样落到演示首页。
4. 演示顶部始终显示 **「演示模式 · 示例数据」** 和 **「退出」**；现场屏显示 **「这是演示数据 / 退出演示」**。
5. 录制时不要点：搜索、手动导入、家人分组名输入框、（真实态的）权限按钮。演示态已隐藏或禁用这些入口。

## 二、分镜表

每个镜头按 3～5 秒排，动作做完后停稳再切下一镜。所有镜头均为演示数据，退出重进内容完全一致。

## 三、收尾与重录

- 点顶部「退出」即可退出演示；演示里的「已取」只改内存，**不写数据库**。
- 重录一条：退出后再点「先看完整演示 / 演示模式」即可。演示集在进程内固定，连进三次画面一致。
- 若录制跨进程：重装/强停后重新进入，相对时长按新锚点生成，件数、排序、商品信息仍完全一致。
- 不建议在演示中打开搜索与手动导入（演示态已隐藏这些入口，避免软键盘与系统面板）。
