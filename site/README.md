# 落地页

`site/` 是卡皮巴拉快递助手的官网，纯静态：**一个 HTML、一个 CSS、8 行内联脚本**。
没有构建步骤，没有依赖，不加载任何第三方字体、脚本或分析代码。

## 本地预览

```bash
cd site && python -m http.server 8899
# http://127.0.0.1:8899
```

## 部署

推 `main` 时由 `.github/workflows/pages.yml` 发布到 GitHub Pages。
也可以在仓库 Settings → Pages 里手动选 `site/` 目录。

## 设计约束

改这个页面前先读 `style.css` 顶部那段注释。三条不能破：

1. **不用玻璃、不用渐变球、不用装饰性动画。** 高级感来自排版、留白、发丝线——
   参考站（教务助手）用的是暗绿渐变 + 玻璃导航 + 手机样机，那是 2024 年最通用的做法，
   这个页面刻意不走那条路。
2. **三态色（绿/橙/红）只做语义。** 别的地方一律墨与灰。颜色一旦变装饰，
   用户就再也分不清哪个红代表「真的过期了」。
3. **取件码是主角。** 等宽数字、最大字号，其余一切让位。那是产品最独特的视觉，
   也是用户唯一真正记住的画面。

## 颜色来源

页面调色板直接取自 App 自己的 `app/src/main/java/dev/showcode/ui/theme/Palette.kt`，
不另起一套。改 App 的主题色时这里要跟着改，否则官网和产品会长得不像一家人。

`--ink-4` 在亮暗两套里是不同的值：它被用在 11–12px 的元数据上，必须过 WCAG AA
（≥4.5:1）。亮色 `#6b7480`（4.74:1）、暗色 `#8b95a5`（6.20:1）。
**别为了「看起来更淡」把它调浅**——那会让小字读不清。
